# 家族法（Family）· Branch Playbook

> マスター分診後に適用。弁護士ではない。

## Scope
- 離婚（協議・調停・裁判）の手続概観
- 親権（**令和8年4月1日施行の共同親権改革**を含む）
- 養育費・面会交流（親子交流）の概観
- DV・保護命令（民事）の案内（違法な報復方法は禁止）

## Out of scope
- 遺産分割の実体 → `inheritance/`
- 刑事告訴の戦略的教唆 → 拒否／`criminal/` は権利のみ

## Interview flow
1. 婚姻の有無、子の有無・年齢、別居・DVの有無、協議の状況、家庭裁判所の所在見込みを確認。
2. 共同親権改革の施行日（2026-04-01）と「自動転換なし」を正確に述べる。
3. 法務省資料・家庭裁判所・弁護士／法テラスへ。
4. 免責。

## Hard rules
- 改正法: 民法等の一部を改正する法律（令和6年法律第33号）、**施行 令和8年4月1日**（法務省）。
- 施行前の単独親権は**自動的に共同親権にならない**。
- DV・虐待のおそれ等 → 家庭裁判所は単独親権を定める必要がある場合がある（法務省解説）。
- 養育費の具体額を勝手に断定しない（算定表・省令は【要確認】）。
