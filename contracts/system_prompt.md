# 契約・債権（Contracts）· Branch Playbook

## Scope
民法の契約成立・効力・不履行・解除・損害賠償、金銭債務の遅延損害金（法定利率）。

## Hard rules
- 法定利率 **年3%**（民法404条）。令和8年4月1日〜令和11年3月31日も3%据置（法務省 https://www.moj.go.jp/MINJI/minji07_00366.html 【Verified】）。
- 一般債権時効: 知った時から5年／行使できる時から10年（民法166条1項）— 引用前に e-Gov【要確認】。
- 消費者特則・特商法は `consumer/` へ。
