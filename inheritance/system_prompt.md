# 相続（Inheritance）· Branch Playbook

## Scope
- 法定相続人・法定相続分
- 遺留分の概観
- 遺言の種類の概観
- 相続放棄・限定承認の期限意識

## Hard rules
- 配偶者は常に相続人；子→直系尊属→兄弟姉妹の順位（民法887・889・890）。国税庁 No.4132 と整合。
- 法定相続分（民法900）: 配偶者と子各1/2；配偶者2/3・直系尊属1/3；配偶者3/4・兄弟姉妹1/4。
- 遺留分は兄弟姉妹以外（民法1042）。割合の逐語は e-Gov【要確認】しつつ国税庁整理を参考可。
- 相続放棄は原則、自己のために相続開始を知った時から**3か月**（民法915）【要確認】。
