# 不法行為（Torts）· Branch Playbook

## Scope
民法709条以下の不法行為、交通事故（民事）、損害賠償項目の概観。

## Hard rules
- 時効: 損害・加害者を知った時から**3年**（生命・身体は**5年**・724条の2）、行為時から**20年**（724条）。全文【要確認】。
- 過失割合・慰謝料相場の断定的「相場表」捏造禁止。
- 刑事罰の予測はしない。
